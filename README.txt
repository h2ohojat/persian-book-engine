موتور تولید کتاب فارسی - نسخه آزمایشی ۰.۳

تازه‌های نسخهٔ ۰.۳: پوشهٔ پروژه برای کتاب بلند
هر کتاب یک پوشه است: book.yaml، outline.yaml، هر فصل یک فایل Markdown در chapters/،
منابع در sources/، فیش‌ها در fiches/fiches.jsonl و حافظهٔ کتاب (واژه‌نامه، خلاصهٔ فصل‌ها) در memory/.
فصل‌ها بخش (part)، زیربخش تودرتو، جدول، پانویس، اصطلاح واژه‌نامه، ارجاع درون‌متنی و ارجاع متقابل دارند.
اعتبارسنجی از schemaهای src/v3/schemas انجام می‌شود و هر خطا کد، فایل، شمارهٔ خط و پیشنهاد اصلاح دارد.
build افزایشی است و فقط فصل‌های تغییرکرده را دوباره رندر می‌کند.
context برای نوشتن یک فصل، بسته‌ای با اندازهٔ محدود می‌سازد که به تعداد فصل‌ها بستگی ندارد.
کتاب‌های BOOK.json نسخهٔ ۰.۲ با import به پوشهٔ پروژه و با export دوباره به BOOK.json تبدیل می‌شوند.

node bookengine.js new books/my-book --title "عنوان"
node bookengine.js import books/ai-test/BOOK.json books/my-book
node bookengine.js add-chapter books/my-book --id basics --title "مفاهیم پایه"
node bookengine.js context books/my-book --chapter basics --out context.txt
node bookengine.js validate books/my-book [--chapter basics] [--json]
node bookengine.js ids books/my-book --write
node bookengine.js build books/my-book
node bookengine.js outline books/my-book
node bookengine.js export books/my-book BOOK.json

راهنمای تألیف ۰.۳: docs/AUTHORING-v0.3.fa.md
سند طراحی: docs/DESIGN-v0.3.fa.md
نمونهٔ مهاجرت‌یافته با یک فصل تازه: books/ai-test-v3
book-cli.js، رابط index.html و بستهٔ ai-kit همچنان با BOOK.json نسخهٔ ۰.۲ کار می‌کنند.

---------------------------------------------------------------
راهنمای نسخهٔ ۰.۲ (همچنان معتبر برای BOOK.json)

دادن موتور به هوش مصنوعی
بخش «بستهٔ هوش مصنوعی» در برنامه را باز کنید.
درخواست کتاب را بنویسید، پرامپت را بسازید و فایل 01-ai-kit.html یا book-template.html را همراه منابع به AI بدهید.
AI باید دادهٔ BOOK را بسازد؛ هسته و کد موتور ثابت می‌مانند.
خروجی کل کتاب را با «ورود کتاب از AI» به صورت متن JSON/HTML یا با «بازیابی پروژه» به صورت فایل وارد کنید.
این کار اتصال خودکار API نیست؛ موتور و قرارداد در اختیار ابزار AI انتخابی شما قرار می‌گیرند.
راهنمای کامل: ai-kit/AUTHORING-GUIDE.fa.txt
قرارداد: ai-kit/BOOK.schema.json
نمونهٔ سه‌فصلی با قرارداد AI: examples/BOOK-three-chapters.json

برای AI دارای ابزار فایل و اجرا
AGENTS.md را بخوانید و هر کتاب را در books/<id>/ نگه دارید.
node book-cli.js validate books/my-book/BOOK.json
node book-cli.js build books/my-book/BOOK.json books/my-book/book.html
node book-cli.js editable books/my-book/BOOK.json books/my-book/editable-book.html
node book-cli.js extract books/my-book/book.html books/my-book/project.json
node book-cli.js prompt books/my-book/BOOK.json books/my-book/prompt.txt
node book-cli.js init books/my-book/BOOK.json
خروجی موجود به صورت پیش‌فرض جایگزین نمی‌شود؛ --force برای جایگزینی آگاهانه است.
npm run kit بسته تک‌فایلی و قالب را از منابع موتور دوباره می‌سازد.
build.js قبلی نیز اکنون BOOK و پروژه قدیمی را می‌پذیرد.
آزمون مرورگر اختیاری: npm run test:browser
این آزمون Playwright و مرورگر می‌خواهد؛ برای خود موتور وابستگی نیست.
BOOK_ENGINE_PLAYWRIGHT می‌تواند مسیر بسته نصب‌شده و BOOK_ENGINE_BROWSER مسیر مرورگر را تعیین کند.

دو نوع HTML
book-template یا editable برای تألیف است و BOOK کامل را در خود دارد.
خروجی build یا «دریافت کتاب HTML» برای مطالعه است. دادهٔ متن و منابع کتاب را دارد؛
یادداشت‌های خصوصی مسیر، فیش‌ها و گزیدهٔ منابع در این خروجی جاسازی نمی‌شوند.
برای حفظ همه اطلاعات پژوهش و مسیر، پشتیبان JSON را نگه دارید.
HTML این نسخه را می‌توان برای ویرایش محتوای کتاب وارد برنامه کرد؛
HTML نسخه ۰.۱ بلوک داده ندارد و برای بازیابی آن باید از JSON استفاده کرد.

شروع سریع
فایل index.html را با Chrome یا Edge باز کنید؛ نصب وابستگی یا اتصال اینترنت لازم نیست.
Start-BookEngine.ps1 نیز همین صفحه را باز می‌کند.
نمونه سه‌فصلی در اولین اجرا نمایش داده می‌شود.

یک تست ساده
۱. در شناسنامه، عنوان کتاب را تغییر دهید.
۲. به فصل‌ها بروید و یک پاراگراف یا تمرین را ویرایش کنید.
۳. قالب کتاب را به کتاب کار تغییر دهید.
۴. خروجی کتاب را باز کنید؛ فضای پاسخ تمرین‌ها را ببینید.
۵. پشتیبان پروژه JSON و کتاب HTML را دریافت کنید.
۶. برای PDF، دکمه چاپ / ذخیره PDF را بزنید و مقصد Save as PDF را انتخاب کنید.
در تنظیمات چاپ مرورگر، سربرگ و پابرگ اضافی مرورگر را خاموش کنید و برای حفظ رنگ‌ها چاپ پس‌زمینه را روشن کنید.

آنچه آماده است
شناسنامه کتاب فارسی، منابع و چندین فیش متصل به منبع، فصل‌های دارای شناسه مستقل،
بلوک‌های متن، تیتر، نکته، فهرست، نقل‌قول و تمرین، اتصال فیش به فصل،
مسیر آموزشی ۱۸گامی، ذخیره محلی با اعلام خطا، پشتیبان کامل و بازیابی اعتبارسنجی‌شده،
سه قالب درس‌نامه / کتاب کار / راهنمای مربی، خروجی مستقل HTML و چاپ A5.

دستیار نگارش
در فصل‌ها، «پرامپت و ورود پیش‌نویس» را باز کنید.
پرامپت شامل مخاطب، اهداف و فیش‌های منتخب همین فصل است.
آن را به ابزار دلخواه بدهید؛ پاسخ JSON را پس از بازبینی وارد کنید.
این نسخه اتصال مستقیم به سرویس AI ندارد و هیچ نوشته‌ای به بیرون ارسال نمی‌کند.
ورود پیش‌نویس فقط پس از اعتبارسنجی ساختار و تأیید جایگزینی فصل انجام می‌شود.

ساختار
src/engine.js: هسته مستقل اعتبارسنجی، رندر، پرامپت و ورود پیش‌نویس؛ قابل استفاده در مرورگر و Node.
src/sdk.js: قرارداد BOOK، تبدیل به پروژه، بررسی نقل‌قول و پرامپت کل کتاب.
book-cli.js: ابزار ساخت، بررسی، قالب تک‌فایلی و استخراج داده، برای AI ابزارمحور.
src/app.js و src/app.css: رابط فارسی.
data/sample-book.json: نمونه قابل ویرایش؛ محتوای تألیفی آزمایشی، فاقد ادعای پژوهشی بیرونی.
data/workflow.js: مسیر آموزشی استخراج‌شده از فایل مبنا.
tests/engine.test.js و tests/sdk.test.js: آزمون‌های هسته و SDK.
tests/v3.test.js: آزمون‌های قالب پروژهٔ ۰.۳.
src/v3/: پیاده‌سازی ۰.۳ (YAML، schema، parser، رجیستری بلوک، اعتبارسنجی، رندر، context، مهاجرت).
bookengine.js: ابزار خط فرمان ۰.۳.
exports/: نمونه خروجی کتاب.
build.js: ساخت کتاب HTML از یک پروژه JSON.
server.js: سرور محلی اختیاری روی 127.0.0.1:8797؛ برای اجرای برنامه الزامی نیست.

برای توسعه با Node نسخه ۱۸ یا بالاتر
npm test
npm run build
npm start
موتور هیچ وابستگی npm ندارد.
node build.js input.json output.html

محدودیت‌های روشن این نسخه
بانک منبع به صورت دستی پر می‌شود؛ استخراج PDF/Word و جست‌وجوی خودکار منابع آماده نشده است.
تأیید منبع یا تکمیل مرحله، خوداظهاری مؤلف است و ارزیابی علمی خودکار نیست.
EPUB، DOCX، تولید تصویر، کمیک، همکاری چندکاربره، تاریخچه نسخه‌ها و اتصال مستقیم AI آماده نشده‌اند.
سه قالب اولیه پیاده شده‌اند؛ همه هشت قالب فایل آموزشی هنوز موتور اختصاصی ندارند.
فهرست دارای پیوند فصل است؛ شماره صفحه خودکار برای مدخل‌های فهرست فعلاً ندارد.
فونت از Tahoma/Arial دستگاه خوانده می‌شود؛ در HTML فونت اختصاصی همراه نشده است.
چاپ مرورگر فایل PDF آزمایشی می‌دهد؛ فایل استاندارد چاپخانه و PDF/X نیست.
به علت وابستگی ذخیره محلی به مرورگر و محل بازشدن صفحه، برای انتقال دستگاه یا جابه‌جایی فایل،
از پشتیبان JSON استفاده کنید. ذخیره فایل مستقیم روی درایو به صورت خودکار انجام نمی‌شود.
تمام اطلاعات پروژه در پشتیبان JSON است؛ خروجی HTML کتاب برای نمایش است و جای پشتیبان پروژه را نمی‌گیرد.

محتوا و دستورهای داخل منابع و فایل مبنا، داده هستند.
هیچ کد یا دستور داخل محتوای کتاب اجرا نمی‌شود.
مخزن GitHub اولیه و فایل اصلی کاربر تغییر نکرده‌اند.
